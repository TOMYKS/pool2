# Simply Pool

Billar 3D para jugar contra la CPU o con otra persona en la misma computadora.

## Controles

| Para… | Hacé esto |
| --- | --- |
| Girar la cámara | Usá las flechas o arrastrá con el clic derecho. |
| Acercar o alejar | Usá la rueda del mouse. |
| Apuntar y golpear | Mantené el clic izquierdo sobre la blanca, llevá el taco hacia atrás y después empujalo hacia adelante sin soltar. Apuntá al centro para un golpe recto o hacia un borde para darle efecto. |
| Regular la fuerza | La marca verde indica un golpe suave, la amarilla uno medio y la roja uno fuerte. Soltá el clic para cancelar el tiro. |
| Colocar la blanca tras una falta | Hacé clic en un lugar libre del paño. |
| Pausar | Presioná **Esc**. La lamparita del menú prende o apaga las luces del bar. |
| Activar o desactivar los poderes | Presioná **Espacio** durante la partida. |

## Reglas básicas

- En el saque tiene que entrar una bola o llegar al menos cuatro bolas de color a las bandas. Si entra la negra en el saque, se reinicia la partida.
- La primera embocada válida después del saque asigna los grupos. Las **lisas** van del 1 al 7 y las **rayadas**, del 9 al 15. Si embocás una de tu grupo sin cometer falta, seguís jugando.
- Si la blanca entra en una tronera, una bola sale de la mesa, no tocás ninguna o tocás primero una bola que no corresponde, el rival puede colocar la blanca donde haya lugar.
- Para ganar, completá tu grupo y embocá la **negra (8)** en un tiro posterior. Si la embocás antes de tiempo o con falta, o si la negra sale de la mesa, perdés.

El **HUD** muestra de quién es el turno, qué bolas quedan por embocar y cuántos tiros dura el poder activo. En **Cómo jugar** podés consultar los controles, las reglas y los poderes.

## Poderes sorpresa

El activador **?** puede aparecer una vez asignados los grupos y después de que cada jugador complete un tiro con su grupo. Se activa cuando lo toca la blanca o cualquier bola de color. El efecto dura entre **1 y 3 tiros posteriores**.

| Poder | Qué hace |
| --- | --- |
| Bolas pesadas | Hace que las bolas de color pesen más. |
| Rebote extra | Hace que las bolas reboten más contra las bandas. |
| Bolas grandes | Agranda las bolas de color. |
| Pared | Agrega una barrera que rebota las bolas. |
| Bolas invisibles | Oculta las bolas de color y deja sus sombras como pista. |
| Bolas falsas | Permite que algunas bolas atraviesen a otras. |
| Troneras bloqueadas | Tapa algunas o todas las troneras temporalmente. |
| Ochos malditos | Disfraza de negras las bolas de color y deja una visible por grupo. Si entra esa bola, se revela otra de su grupo si queda alguna.  |
